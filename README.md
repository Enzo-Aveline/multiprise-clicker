# Multiprise Clicker

Un jeu incrémental (Clicker) développé en React et Vite, sur le thème de l'électricité.

## Fonctionnalités (MVP)
- Clic sur la multiprise pour générer des Watts avec animations rétro d'étincelles.
- Achat de bâtiments dans la boutique pour générer des revenus passifs (Watts par seconde).
- Sauvegarde automatique en temps réel via le `localStorage` du navigateur.
- Design Mobile First, ambiance sombre et "fluo" rétro.

## Stack
- Vite
- React
- Vanilla CSS

## Installation
Puisque le projet est configuré avec Vite, vous pouvez l'installer et le lancer avec les commandes standards :
```bash
npm install
npm run dev
```

## Bâtiments disponibles
- **Pile 9V** (+1 W/s)
- **Dynamo** (+5 W/s)
- **Eolienne Balcon** (+20 W/s)
- **Compteur Trafique** (+100 W/s)
